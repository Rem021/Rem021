# Rem021

I build tools that make AI coding agents safer and easier to run on a Mac, research camera firmware, and
make small browser games.

做让 AI 编码 Agent 在 Mac 上更安全、更省心的工具，也研究相机固件、写网页小游戏。

## Developer tools · 开发工具

| Project | What it does | Start |
| :--- | :--- | :--- |
| **[Orca Multi-Agent Blueprint](https://github.com/Rem021/orca-multi-agent-blueprint)** | Run Claude Code, Codex, Gemini and other coding agents side by side on one Mac: a Git worktree per task, a guardrail before every command, shared rules and skills, encrypted backups.<br>多 Agent 并行开发的 Mac 工作区：工作树隔离、命令护栏、统一规则、加密备份。 | [Quick start](https://github.com/Rem021/orca-multi-agent-blueprint#quick-start) |
| **[Workspace Naming Guard](https://github.com/Rem021/workspace-naming-guard)** | Orca plugin that names workspaces `Project｜Topic` automatically, with rename history and Undo.<br>自动为 Orca 工作区补上项目名。 | [Install](https://github.com/Rem021/workspace-naming-guard#install) |
